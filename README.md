## Install on iPhone

The IPA is unsigned. iOS cannot install it by tapping the download in Safari.

1. Download the IPA on a Windows or Mac computer.
2. Install [Sideloadly](https://sideloadly.io/#download) or [AltStore Classic](https://faq.altstore.io/altstore-classic/altserver).
3. Use your Apple ID in the sideloading tool to sign and install the IPA on your iPhone.
4. If iOS asks you to trust the app, open **Settings → General → VPN & Device Management** and trust your Apple ID's developer profile.

Free Apple ID sideloads need to be refreshed every seven days. This IPA excludes the Apple Watch companion; widgets and Live Activities may also be limited after resigning. A source build signed with your own Apple team is needed for full Watch support.

The [latest release](https://github.com/compscihas/Stasis-Downloads/releases/latest) includes `SHA256SUMS.txt` so you can verify the download. The Stasis source repository remains private; this repository contains download files and install instructions only.
